### 🎯 Objectif 
Cet exercice vous permettra de :

* Lire des données à partir d’un fichier texte
* Utiliser un ``ListView`` avec une ImageList
* Associer dynamiquement des images à des éléments d’interface

### 🛠️ Instructions

Dans cet exercice, vous devez compléter une application Windows Forms permettant d’afficher une liste d’acteurs avec leur photo à l’aide d’un contrôle ``ListView``.

Les noms des acteurs sont lus à partir d’un fichier texte *Acteurs.txt*, et chaque acteur possède une image correspondante dans le dossier *Images*.

### 📋 Liste des TODOs à compléter:

Complétez les TODOs du fichier **`Frm1.cs`**  :

- TODO 1 : Charger les noms des acteurs à partir du fichier *Acteurs.txt* dans une liste
- TODO 2 : Afficher les acteurs dans un ListView en mode LargeIcon avec leur image
